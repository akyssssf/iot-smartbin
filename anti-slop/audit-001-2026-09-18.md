# antislop audit 001, 2026-09-18

Lingkup: `index.html` (landing) dan `dashboard.html` (mockup) beserta CSS/JS-nya.
Skill: core + antislop-ui + antislop-copywriting + antislop-human + antislop-layoutmobile.
Arah desain: `DESIGN.md` (ditranskripsi dari brief pemilik). Design Read: landing showcase proyek
kampus IoT untuk dosen dan pengunjung, bahasa visual eco-clean dengan card rounded, dial ENERGY 2 /
RHYTHM 2 / MOTION 2.

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.
Status: **SUDAH DIPERBAIKI** = diterapkan tanpa mengubah copy, struktur, atau desain card
(hanya nilai warna, fokus, area sentuh, keyboard). Item yang semula MENUNGGU disetujui pemilik pada 18 Sep dan diterapkan
(lihat `audit-001-followup.md`).

## HIGH (Hard Gate)

1. **R-02 Em dash di teks UI.** `index.html`: judul tab, teks fitur "Dashboard mobile", CTA band.
   `dashboard.html`: catatan samping dan hint (9). `js/dashboard.js`: teks toast/hint (3).
   Perbaikan: ganti dengan koma/titik dua, kata tidak diubah. **SUDAH DIPERBAIKI** (persetujuan 18 Sep).
2. **R-25 Kontras teks tombol.** Putih di atas green-600 `.btn-primary` = 3.30:1 (teks tombol 15px
   tebal bukan "large"). Juga strip solusi (gradasi sampai #1f9d55 = 3.49:1), toast "terima kasih",
   paragraf CTA band (putih 85% di biru = 4.02:1). Perbaikan: tombol memakai green-700 (5.02:1),
   strip green-800→green-700, paragraf putih/green-50 solid. **SUDAH DIPERBAIKI.**
3. **R-25 Teks gray-400 (2.54:1).** Label tab bawah nonaktif, waktu di riwayat, skala slider,
   teks "tentang", indikator platform (dashboard); panah diagram arsitektur (landing).
   Perbaikan: gray-500 (4.83:1). **SUDAH DIPERBAIKI.**
4. **R-25 Pill status kuning/merah.** amber-600 di amber-100 = 2.86:1, red-600 di red-100 = 3.95:1,
   banner kuning 3.07:1, tombol merah 4.41:1. Perbaikan: amber-700 (4.51:1) dan red-700 (5.30:1),
   tombol reset solid red-600 (4.83:1). **SUDAH DIPERBAIKI.**
5. **R-26 / R-38 Tautan hantu di footer.** "Repositori GitHub" → `github.com/username/smart-bin`,
   "email@kampus.ac.id", "Simulasi Wokwi" → beranda wokwi.com (bukan proyekmu). Perbaikan: isi URL
   asli, atau lepas tautannya dan beri label "Segera tersedia". **SUDAH DIPERBAIKI**: dilepas tautannya, berlabel "segera tersedia" sampai URL asli ada.
6. **R-32 / R-26 Keyboard.** Modal reset tidak bisa ditutup dengan Escape; menu mobile juga.
   Tidak ada gaya `:focus-visible` (outline bawaan masih ada, tapi tipis di atas tombol hijau).
   Perbaikan: Escape menutup modal dan menu, fokus dikembalikan ke tombol pemicu; cincin fokus
   biru-tua 3px global. **SUDAH DIPERBAIKI.**
7. **R-03 Area sentuh < 44px.** Dashboard: `.icon-btn` 38px, `.switch` 27px, "Simulasi deteksi"
   ±22px, tombol segmented ±40px. Landing: "Reset tampilan" ±34px, tautan footer, hamburger 42px.
   Perbaikan: min-height 44 / area sentuh pseudo-element tanpa mengubah tampilan. **SUDAH DIPERBAIKI.**
8. **R-38 Status "hidup" yang direkayasa tanpa label.** Kartu mengambang hero "ESP32 Online · MQTT"
   dan "Deteksi terakhir Organik · 14:32" tampil seperti data sungguhan. Di dashboard, angka simulasi
   sudah diberi pill "Data simulasi" di header stage, tapi tidak di dalam frame ponsel.
   Perbaikan: tambah label kecil "contoh" pada kartu hero, atau catatan "data simulasi" di dalam
   aplikasi. **SUDAH DIPERBAIKI**: tag kecil "contoh" pada kedua kartu.
9. **R-27 State UI.** Dashboard punya empty state (riwayat) tetapi belum ada loading state maupun
   error state (mis. alat offline / MQTT terputus). Perbaikan: banner "Alat offline" + skeleton
   singkat saat "sinkron". **SUDAH DIPERBAIKI**: loading state saat dibuka, error state "Alat tidak terhubung" (uji dari Pengaturan → Koneksi alat).

## MEDIUM (Purpose-Gate)

10. **R-09 Eyebrow badge di atas H1.** Pill "Proyek IoT · D3 Teknik Informatika" di hero adalah
    pola template. Isinya memang informasi yang tidak ada di H1, jadi ada fungsinya. Opsi: jadikan
    baris teks biasa tanpa pill, atau tetap dengan alasan tercatat. **SUDAH DIPERBAIKI**: jadi baris teks `.hero-kicker`.
11. **R-08 Panah di CTA.** Tiga tombol memakai ikon panah dekoratif (hero, strip solusi, CTA band);
    tiga panah lain di diagram arsitektur adalah alur data (sah). Opsi: sisakan pada satu CTA utama.
    **SUDAH DIPERBAIKI**: panah hanya di CTA utama hero.
12. **R-06 Label huruf besar berjarak lebar.** `.eyebrow` (landing), `.card-title`, `.stage-notes h2`
    (dashboard). Alasan yang bisa ditulis: label kecil pembeda dari judul. Opsi: kurangi tracking ke
    .04em atau ubah ke sentence case. **SUDAH DIPERBAIKI**: tracking .03–.04em; huruf besar tetap, alasan tercatat di DESIGN.md.
13. **R-04 Ikon Lucide di seluruh halaman.** Relevan per konten dan diminta eksplisit di brief
    ("ikon sederhana Lucide/Feather"), jadi alasan tercatat di DESIGN.md. **DIPERTAHANKAN.**
14. **R-19 Animasi tanpa akhir.** Kartu mengambang hero naik-turun selamanya (`floaty`); titik hijau
    "Online" berdenyut selamanya (menandai state nyata, tapi denyutnya dekoratif). Putaran model 3D
    dan demo sampah punya tujuan (menjelaskan cara kerja). Opsi: hapus `floaty`, titik statis.
    **SUDAH DIPERBAIKI**: `floaty` dihapus, titik statis.
15. **R-14 Card fitur & komponen seragam.** Empat card fitur identik ukuran/ikon/padding. Alasan yang
    bisa ditulis: keempat fitur setara bobotnya. Kamu minta card dipertahankan. **DIPERTAHANKAN.**
16. **R-12 Hover mengangkat semua card.** Card masalah/langkah/fitur/komponen naik + bayangan besar
    saat hover padahal bukan tautan (mengesankan bisa diklik). Opsi: hapus efek hover pada card
    non-interaktif. **SUDAH DIPERBAIKI.**

## LOW (Quality Locks)

17. **R-29 Warna kelima.** Laci anorganik di model 3D berwarna coral (dari GLB), sedangkan situs
    memakai biru untuk anorganik. Opsi: timpa material `mat_anorganic_coral` ke biru dari JS agar
    palet tetap hijau + biru + status. **SUDAH DIPERBAIKI** di `model-viewer.js`.
18. **R-05 Variasi latar.** Section bergantian putih/abu; komposisinya sekarang sudah bervariasi
    (foto, 3D, timeline), jadi tidak lagi "hanya bergantian warna". Catatan saja.

R-17/R-18 tidak ada statistik/testimoni palsu (angka dashboard berlabel simulasi, lihat #8).
R-24 semua tautan nav punya section. R-30 bukan tiruan produk lain. R-33 tidak ada skrip patch di
repo. R-11 radius bervariasi (tombol pill, card 16px, foto 28px).
